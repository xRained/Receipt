# Jolyn TAE

**Tangaw, Atiris, Esmiringhoy**

Material Expense entry with all payment modes, editable image-to-column drafts, shared supplier/Chart of Accounts lookup, monthly Cash Voucher imports, and receipt-presence matching. Payment and voucher totals are not forced to reconcile.

Application source lives in `receipt-app/`.

- Current workflow: [Material Expense guide](receipt-app/MATERIAL_EXPENSE_GUIDE.md)
- Local setup: [README](receipt-app/README.md)
- Vercel preview: [Deployment guide](receipt-app/DEPLOYMENT.md)

For Vercel, choose **Root Directory: receipt-app**. The hosted preview starts empty and is read-only; persistent storage and access control are required before storing real records online.

Databases, Excel files, images, backups, financial audit reports and credentials are excluded from this repository.
