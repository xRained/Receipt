# Jolyn TAE

**Tangaw, Atiris, Esmiringhoy**

An English-language receipt checklist comparing September online Material Expense payments with the September Cash Voucher register. Filter by account, inspect receipt evidence, and export a checklist without reconciling aggregate totals.

Application source lives in `receipt-app/`.

- Local setup: [receipt-app/README.md](receipt-app/README.md)
- Current workflow: [receipt-app/STEP1.md](receipt-app/STEP1.md)
- Vercel preview: [receipt-app/DEPLOYMENT.md](receipt-app/DEPLOYMENT.md)

For Vercel, choose **Root Directory: receipt-app**. The hosted preview starts empty and is read-only; persistent storage and access control are required before using real financial records online.

Financial records, Excel files, receipt images, backups and credentials are intentionally excluded from this repository.
